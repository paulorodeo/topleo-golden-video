# Contributing

Thank you for your interest in contributing to TopLeo Golden Video.

This project follows a Documentation First philosophy.

Before implementing new features, please ensure the architecture and documentation are updated.

---

## Development Principles

- Documentation First
- Keep scripts simple and modular.
- Preserve backward compatibility whenever possible.
- Follow the official Golden Video Profile.
- Keep commits small and descriptive.

---

## Workflow

1. Fork the repository.
2. Create a feature branch.
3. Update documentation when necessary.
4. Submit a Pull Request.

---

## Coding Guidelines

- Bash scripts should use strict mode whenever possible.
- Avoid hardcoded paths.
- Prefer reusable functions.
- Keep the project portable across Linux distributions.

---

## Reporting Issues

Please include:

- Operating System
- HandBrake Version
- FFmpeg Version
- Steps to reproduce
- Expected behavior
- Actual behavior

---

Thank you for helping improve TopLeo Golden Video.
